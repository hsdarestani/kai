# KAI Dienstleistungen

Neues Designkonzept für KAI Dienstleistungen.

## Konzept

Die Seite wurde als moderne einseitige Unternehmensseite umgesetzt. Der Aufbau orientiert sich an klassischen Bau und Dienstleistungsseiten mit großem Hero Bereich, klaren Leistungsblöcken, Projektbildern, Prozessdarstellung und einer direkten Kontaktfläche.

Die beiden Themen Reinigung und Sanierung erscheinen jetzt als Teile einer gemeinsamen Marke statt als getrennte Einstiege.
